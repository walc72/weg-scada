# Módulo Caudales — Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Caudal por bomba (manual por nominal o real con TUF-2000SW vía PAS600, propio o de colector), visible en tarjetas, Tendencias → Caudales y volumen en reportes, bajo el módulo `caudales` (caudalímetros = nivel A).

**Architecture:** La config suma `devices[].caudal` y `flowmeters[]`. El poller lee los TUF (lógica pura en `tuf.js` y `flow.js`), publica `weg/flow/<n>` + `flow_data` y agrega `flow` a cada bomba. La API valida, sincroniza renombres/bajas y calcula volúmenes en `generateSummary` con el patrón contador/integral de la energía. El portal muestra el cuadro, la pestaña y las columnas. La réplica copia el nuevo tópico y la nueva medición.

**Tech Stack:** Node 20 (`node:test`), Express, Modbus TCP propio (`connections.poll`), InfluxDB Flux, MQTT, React + TS + Zustand.

**Spec:** `docs/superpowers/specs/2026-10-22-caudales-design.md`

## Global Constraints

- Unidad m³/h; volumen m³ (integral de m³/h en segundos ÷ 3600).
- `caudal.modo` ∈ {`manual`, `real`}; `nominal` ≥ 0. `flowmeters[]` campos: `name, type: 'TUF2000', ip, port, unitId, wordOrder: 'LE'|'BE' (def LE), totalMultiplier > 0 (def 1), bombas: string[], enabled`.
- Registros TUF (base 1): 1–2 caudal REAL4, 9–10 total LONG, 11–12 fracción REAL4, 72 error. `total = (LONG + fracción) × totalMultiplier`.
- MQTT `weg/flow/<sanitizeTopic(name)>` retenido `{ name, flow, total, error, online, ts }`; Influx `flow_data,name=<name>` campos `flow,total,error,online`.
- Bomba: payload y `drive_data` suman `flow` (o ausente), `flowMode` (`manual`|`real`|`colector`), `flowMeter` (en colector).
- Mensajes exactos: `IMBIL 5 ya está en el caudalímetro Colector Norte`, `IMBIL 5: modo Real requiere un caudalímetro`, `La licencia no incluye el módulo caudales`.
- Fuentes de volumen: `estimado`, `totalizador`, `integrado`.
- `nodered/weg-api/src/services/license.js` y `nodered/weg-modbus-poller/src/license.js` idénticos (test).
- Sin dependencias nuevas. Spanish UI con voseo. Bombas sin `caudal` no cambian en nada (payload, Influx, UI).
- Tests: `MSYS_NO_PATHCONV=1 wsl -d Ubuntu -u root -- bash <scratchpad>/nodetest.sh <pkg> <files|test/>`; frontend `<scratchpad>/frontbuild.sh "<needle>"`. Commits por heredoc con `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

- Bomba en modo `real` cuyo caudalímetro está fuera de licencia o deshabilitado → `flow` ausente y aviso, nunca el nominal (test Task 3).
- Totalizador del TUF que vuelve a 0 a mitad del día → fuente `integrado`, no volumen negativo (test Task 4).
- Bomba manual OFFLINE o con dato viejo → `flow` ausente y no suma volumen (test Task 3).
- Renombrar una bomba que está en un colector → el colector se actualiza en el mismo guardado (test Task 2).
- Config de planta actual (16 bombas, 4 medidores, sin `flowmeters` ni `caudal`) → validación pasa y payloads idénticos a hoy (test Task 2 y Task 3).
