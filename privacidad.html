Política de privacidad

Vigente desde el 23 de octubre de 2026.

WEG SCADA es un sistema de supervisión que se instala en un servidor propio de cada cliente. Esta política explica qué datos usa cuando el administrador de una planta conecta Google Drive para guardar copias de seguridad.

Qué datos de Google usamos

  • Permiso drive.file: el sistema solo puede crear, leer y borrar los archivos y carpetas que él mismo creó en el Drive. No ve ni modifica ningún otro archivo de la cuenta.
  • Dirección de correo de la cuenta (permisos openid y email): se muestra en el portal para que el administrador sepa qué cuenta está conectada.

Para qué los usamos

Únicamente para subir copias de seguridad cifradas de la configuración y del histórico de la planta a una carpeta llamada "WEG SCADA backups", y para borrar las copias más antiguas según la cantidad que el administrador decide conservar.

Dónde se guardan

La autorización de Google (el token de acceso) se guarda solo en el servidor del cliente donde está instalado el sistema. No se envía a terceros ni al integrador del sistema. Las copias de seguridad se cifran en ese servidor antes de subirlas, con una frase que define el cliente.

Con quién se comparten

Con nadie. Los datos no se venden, no se usan para publicidad y no se comparten con terceros.

Cómo revocar el acceso

El administrador puede desconectar Google Drive desde el portal (Configuración → Backups → Desconectar), lo que revoca la autorización y borra el token del servidor. También se puede quitar el acceso en cualquier momento desde la cuenta de Google, en myaccount.google.com/permissions.

Uso de la información de Google

El uso y la transferencia de información recibida de las API de Google se ajustan a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.
