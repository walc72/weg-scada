# weg-scada — instrucciones para agentes

- **Interfaz**: toda pantalla, componente o diálogo nuevo o modificado sigue la línea de diseño industrial de [`docs/diseno-industrial.md`](docs/diseno-industrial.md). Leela antes de tocar `frontend-react/` y usá su checklist en cada PR con UI.
- Textos de la interfaz y commits en español rioplatense.
- Flujo: rama → PR → CI → merge solo con OK del usuario → tag `vX.Y.Z` → deploy a planta solo con OK explícito.
